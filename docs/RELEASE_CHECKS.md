# NFSKR v1.1 검증 내역

- 한국어 번역 총 **8,206개 문자열 ID**, 두 ID의 이름 표기 **엠마누엘**로 통일 (3회)
- Windows x64 PyInstaller 빌드 및 내장 구성요소 17개 자체검사 통과
- 기존 모드 2개 선택 시 617개 리소스 병합 검사 통과
- 기존 모드 6개 통합 시 **4,378개 리소스** 병합 정적 검사 통과
- 기존 NFSKR 프로필 갱신, 모드 추가 후 재설치, 원복 관련 **30개 회귀 테스트** 통과
- 실제 Windows UI에서 `업데이트` 버튼과 모드 목록 표시 확인
- Frosty 프로필 복사본을 이용한 격리형 업데이트/복원 검증 통과
- 게임 원본·사용자 세이브·실제 원본 Frosty 모드를 변경하지 않는 방식으로 작업

이 항목은 **정적/격리형 테스트 결과**야. 어떤 타사 모드라도 전부 무손실 병합될 것이라거나 모든 기기에서 게임 플레이가 성공한다고 보증하지는 않아.
