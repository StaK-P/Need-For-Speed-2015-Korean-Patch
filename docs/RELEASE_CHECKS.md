# NFSKR v1.1 검증 내역

다음 항목에 대해 개발 및 정적 검증을 수행했습니다.

- 한국어 번역 **8,206개 문자열 ID**를 유지하고, 두 개 ID의 인물 이름 표기 3곳을 **‘엠마누엘’**로 통일했습니다.
- Windows x64 PyInstaller 실행 파일을 빌드하고 내장 구성요소 **17개 자체 검사**를 통과했습니다.
- 기존 모드 2개를 선택한 **617개 리소스 병합** 검사를 통과했습니다.
- 기존 모드 6개와 **4,378개 리소스 병합**의 정적 검사를 통과했습니다.
- 기존 NFSKR 프로필 갱신, 모드 추가 후 재적용 및 직전 구성 복원에 대한 **30개 회귀 테스트**를 통과했습니다.
- 실제 Windows GUI에서 **업데이트** 버튼과 원본 모드 목록이 정상 표시되는 것을 확인했습니다.
- Frosty 프로필 복사본을 사용한 격리 환경에서 업데이트 및 복원 절차를 검증했습니다.

위 결과는 **정적 검사 및 격리된 테스트 환경의 결과**입니다. 모든 타사 모드와의 무손실 호환성이나 모든 PC에서의 실제 게임 플레이를 보장하지는 않습니다.

자세한 변경 사항은 [변경 내역](../CHANGELOG.md)을 확인해 주세요.
